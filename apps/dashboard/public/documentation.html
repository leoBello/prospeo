Prospeo — Intégration Vercel

Prospeo génère un site web pour chacun de vos prospects et le déploie sur Vercel, sous votre propre compte.

En connectant votre compte Vercel à Prospeo, vous autorisez l'outil à :

  • créer des projets et des déploiements sur votre compte ;
  • retirer un déploiement (dépublier un site) quand vous le demandez.

Prospeo n'accède à rien d'autre sur votre compte Vercel.
